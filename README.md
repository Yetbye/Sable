# sable

> 万物归于灰，灰中仍有字。

## 设计说明

- 风格协议继承 [Venus](https://github.com/) 可组合设计系统的 Base 层（排版、间距、缓动），Palette 为定制「冷灰残红」：青灰板岩为主，干涸朱红仅作印章与眉标之用。
- 视觉主图为 AI 生成的水墨意象，无文字；海报为黑客松原始交付物。
- 打开方式：直接用浏览器打开 `index.html`，或将仓库部署至 GitHub Pages。
